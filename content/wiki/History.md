# History

A running record of how the project's framing has shifted and the conversations that drove it. Source of truth for "why does the wiki say X now when it used to say Y."

## Framing shifts

- **2026-04-16** — Kickoff. First vision docs drafted: an Amsterdam buurt-scoped, society-owned, fediverse-native civic layer — an alternative to Nextdoor, fused with gemeente function rather than adjacent to it. Preserved in git history at commit `c701bee`.
- **2026-05-22** — Briefing with Roy Bekhuis (see [[Meeting-2026-05-22]]) widens the scope from a buurt social network to a location × theme civic community layer. Committed on 2026-05-25 as `8fa7911`. See [[Vision]] for the current thesis.
